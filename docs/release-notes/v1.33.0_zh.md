# v1.33.0 — Telegram：它的嘴、邮差的按钮、多一扇聊天窗

2026-11-17。全部新增，接口不改；升级 `git pull`。不要模型（聊天窗借的是你已经在跑的 Anchor 代理）。**没配 bot，这一整件不存在。**

```
export ANCHOR_TELEGRAM_TOKEN=123456:ABC...     # 找 @BotFather 要
python3 anchor_telegram.py --whoami            # 先给你的 bot 发一句话，再跑这个，会打印你的 chat id
export ANCHOR_TELEGRAM_CHAT_ID=...             # 这只 bot 只听、只写这一个聊天

python3 anchor_telegram.py --db-path ./anchor_data --send "hello"    # 试嘴
python3 anchor_telegram.py --db-path ./anchor_data --poll            # 常驻：按钮 + 命令 + 聊天窗
```

三样东西，各自能单独用。

## 一张单向的嘴 `send_telegram`

AI 多一个工具，能给你发消息——从心跳里、从房间里、从任何它手里有工具的地方。只到那一个聊天。**不带定时、不带配额**：因为定时器响了才发的「想你了」是表演，不是它想说。（有一根保险丝，一小时 30 条，唯一的用处是掐断失控的循环。）

回执只有两种，都是大白话：「已送到」或「**没送到**——什么都没到对方那里」加原因。回执如果在没发出去的时候也说「已发」，就是在教它相信自己联系上了人。

## 邮差的按钮

`--poll` 跑着的时候，邮差发件箱（v1.32）里每一张待放行的回信草稿都会带着两个按钮发给你：**Send / Discard**。草稿被它重写过会再发一次。

- 按钮由机器处理，**永远不会变成一条给模型的消息**。
- 只认配置的那个 chat id 按的；别人按了不算。
- 按两次只发一次；发成功了邮差的账才动。

命令：`/outbox`（把待发的再列一遍）、`/status`。

## 多一扇聊天窗（要打开才有：`ANCHOR_TELEGRAM_CHAT_URL`）

```
export ANCHOR_TELEGRAM_CHAT_URL=http://127.0.0.1:8210/v1     # 你的 Anchor 代理
```

你在 bot 里说的话，会被送到**你别的窗口在用的同一个聊天入口**——Anchor 代理——回答原路发回来。这是整个设计的全部要点：一个脑子、一份记忆，只是多了一扇窗。给 bot 单配一小段提示词、单存一份聊天记录，得到的是第二个更薄的它，而且它自己知道自己不是原来那个。所以这个模块从不直接找模型，也不存任何记忆；它只留这扇窗的逐字记录（`<db>/telegram/window.jsonl`）。

- 它用嘴主动发过的消息也记在这扇窗里。它先开口、你后回话时，它之前说的那句会带在你第一句话前面——聊天那头知道自己一小时前写了什么。
- 一次只跑一轮；几秒内连发的几条并成一轮回答。
- 安静超过 12 小时自动开新窗，`/new` 立刻开；只是逐字记录从头开始，记忆照旧。
- 出错用固定的机器口吻回「[machine] this turn did not run: …」，从不冒它的名。
- 只读文字；图片、语音、文件不读。

## 设置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `ANCHOR_TELEGRAM_TOKEN` / `ANCHOR_TELEGRAM_CHAT_ID` | — | 两个都有才启用。只从环境变量读 |
| `ANCHOR_TELEGRAM_CHAT_URL` | 空 | 填 Anchor 代理的 `/v1` 地址才开聊天窗 |
| `ANCHOR_TELEGRAM_CHAT_MODEL` / `ANCHOR_TELEGRAM_CHAT_KEY` | 沿用上游模型 / 空 | 代理需要时 |
| `ANCHOR_TELEGRAM_NEW_WINDOW_HOURS` / `ANCHOR_TELEGRAM_DEBOUNCE` | 12 / 4 | |

## 这一版验到哪儿

实跑过的：聊天窗经**真的 Anchor 代理**接本机模型走了一轮（代理自己的原话记录里有这一轮，回答用到了 pinned 层）；配了 token 工具才出现、没配就没有。**没对真实的 Telegram 服务器跑过**（没有可用于测试的 bot）：发消息、长轮询、按钮回调这几个调用和老家跑了两个多月的是同一套，测试里用的是假接口。第一次用请先 `--send` 试一条。
