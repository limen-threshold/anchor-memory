# v1.31.0 — the small books: memo, permanent quotes, failure log, session-state readout

2026-11-17. All additions, no interface changes; upgrade with `git pull`. None of the four needs a model.

## Why

Semantic search is good at "what is related to this". It is not good at three things: a promise with a due date, a sentence that must not change by a word, and "I remembered that wrong last time". This release gives each of those a place of its own, plus a readout that tells the AI how old its own state file is.

## Memo — `memo_jot` / `memo_edit` / `read_memo`

"I'll look into that later", said in passing, is a promise with a due date — and a due date is exactly what similarity search cannot guarantee to surface. So, a narrow pen:

- `memo_jot(text)`: appends one line to `<db>/notebook/memo.md`, dated by the machine, capped at 500 chars. **Append only** — no path, no overwrite, newlines are folded into the one line (so it is safe to hold while reading text from outside). The same line is stored as a memory (tag `memo`), so search reaches it too.
- `memo_edit(old_string, new_string)`: exact replacement, for striking a line that is done (`~~…~~` plus what came of it) or fixing one. `old_string` must occur exactly once, otherwise nothing changes and the receipt says why; the previous version is backed up.
- `read_memo`: open lines by default.

**The machine hands the memo back** (the `notebook` field of `wakeup`; before every heartbeat and journal turn): the oldest open lines past a day, as written — do it, store it, strike it, or leave it; the latest lines of the last two days are shown as written too. A note nobody hands back is a note not taken.

## Permanent quotes — `keep_quote`

Sentences that must survive every rewrite of the session state should not live inside the session state: sooner or later a rewrite drops them. `keep_quote(quote, who, note)` appends one dated quotation line to `<pinned>/permanent_quotes.md`, which is loaded with the identity files in every window. A sentence already there is not added twice. Changing or removing a line goes through `write_identity_file` (the previous version is archived). If your pinned directory has an `_order.txt` that does not list the file, the receipt says it will not be loaded.

## Failure log — `log_failure` / `list_failures`

"That memory was wrong" needs a safe way out: append-only, **never rewriting a memory**. Seven types: bundled (two facts fused into one memory), ghost (cited a memory that never existed), evaporation (a real memory that should have surfaced did not), hallucination (a fact in no memory), misrecall (the wrong memory surfaced), outdated (stale treated as current), tier_error (wrong tier). The subject is always "I". Stored in `<db>/notebook/failures.jsonl`, with a readable `failure_log.md` whose first lines state the blind spot: only failures that surfaced and were caught are here, not all of them.

## Session-state readout

Facts, not instructions:

- when `session_state.md` was last rewritten, and how many days ago;
- which of its lines say "today / tomorrow / soon" and were first written on a day that has passed (dated from the earlier versions in `session_state_archive/`; a lightly edited line is recognised as the same line);
- how many lines the quotes file has and when it last changed.

Shown in `wakeup` and in heartbeat and journal turns. The pen is `write_session_state`; whether to pick it up is the AI's call.

On the write side there is a receipt: when `write_session_state` sees a line with a relative time word and no date on the same line, it lists those lines — a later window would read "tomorrow" as the day after the day it is read. English and Chinese time words are recognised.

## A new guard: the prompt pasted back into its own files

In a real run, a local 30B model writing its session state during a heartbeat pasted the whole system prompt into it (quotes, the old state, the door sign). Now:

- `write_session_state` refuses text that has the `[continuity]` header anywhere but at the very top (it belongs only there, and the machine adds it), says why, and leaves the old file alone;
- in heartbeat, room and journal turns, anything written to the AI's own files that contains a sentence from the door sign is refused the same way.
