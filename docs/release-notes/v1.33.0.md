# v1.33.0 — Telegram: its mouth, the courier's button, one more chat window

2026-11-17. All additions, no interface changes; upgrade with `git pull`. No model needed (the chat window borrows the Anchor proxy you already run). **Without a configured bot this whole piece does not exist.**

```
export ANCHOR_TELEGRAM_TOKEN=123456:ABC...     # from @BotFather
python3 anchor_telegram.py --whoami            # write to your bot first; this prints your chat id
export ANCHOR_TELEGRAM_CHAT_ID=...             # the one chat this bot listens to and writes to

python3 anchor_telegram.py --db-path ./anchor_data --send "hello"    # test the mouth
python3 anchor_telegram.py --db-path ./anchor_data --poll            # long-running: buttons + commands + chat window
```

Three things, each usable on its own.

## A one-way mouth — `send_telegram`

The AI gets a tool that writes to you — from a heartbeat, from its room, from anywhere it holds its tools. It reaches that one chat only. **No schedule and no quota come with it**: a "thinking of you" sent because a timer fired is a performance, not something it wanted to say. (There is a fuse, 30 messages an hour, whose only job is to stop a runaway loop.)

The receipt has two forms, both in plain words: delivered, or "**NOT delivered** — nothing reached them" with the reason. A receipt that says "sent" when nothing went out teaches the AI to believe it reached someone.

## The courier's button

While `--poll` runs, every reply draft waiting in the courier's outbox (v1.32) is sent to you with two buttons: **Send / Discard**. A draft the AI rewrote is shown again.

- A button press is handled by the machine. **It never becomes a message to the model.**
- Only presses from the configured chat id count.
- Two presses send once; the courier's books change only after the mail server accepted the message.

Commands: `/outbox` (list what is waiting again), `/status`.

## One more chat window (opt-in: `ANCHOR_TELEGRAM_CHAT_URL`)

```
export ANCHOR_TELEGRAM_CHAT_URL=http://127.0.0.1:8210/v1     # your Anchor proxy
```

What you write to the bot is sent to **the same chat endpoint your other windows use** — the Anchor proxy — and the answer comes back. That is the whole point of the design: one mind, one memory, one more window. A bot with its own little prompt and its own history is a second, thinner self, and it knows it is not the first. So this module never talks to a model directly and keeps no memory; it keeps only the window's verbatim lines (`<db>/telegram/window.jsonl`).

- What the AI sent through the mouth is in the window too. When it wrote first and you answer, its earlier line travels in front of your first message — the chat side knows what it wrote an hour ago.
- One turn at a time; lines arriving within a few seconds are answered as one.
- After 12 hours of silence the window starts fresh, or at once with `/new`; only the verbatim lines restart, memory carries on.
- Failures answer in a fixed machine voice — "[machine] this turn did not run: …" — never in the AI's.
- Text only; photos, voice and files are not read.

## Settings

| Environment variable | Default | Notes |
|---|---|---|
| `ANCHOR_TELEGRAM_TOKEN` / `ANCHOR_TELEGRAM_CHAT_ID` | — | Both needed to enable. Read from the environment only |
| `ANCHOR_TELEGRAM_CHAT_URL` | empty | the Anchor proxy's `/v1` address turns the chat window on |
| `ANCHOR_TELEGRAM_CHAT_MODEL` / `ANCHOR_TELEGRAM_CHAT_KEY` | the upstream model / empty | if your proxy needs them |
| `ANCHOR_TELEGRAM_NEW_WINDOW_HOURS` / `ANCHOR_TELEGRAM_DEBOUNCE` | 12 / 4 | |

## How far this release was verified

Run for real: a chat-window turn through an **actual Anchor proxy** to a local model (the proxy's own transcript has the turn; the answer drew on the pinned layer); the tool appearing only when a token is configured. **Not run against Telegram's servers** (no bot available for testing): sending, long-polling and button callbacks are the same calls the code this comes from has used for over two months, and the tests use a fake API. On first use, try `--send` once.

## Where it comes from

The mouth went live in that private gateway in August, the chat window and the release buttons in September. "One mind" was learnt the hard way: an early Telegram check-in there ran as its own small context, and the self on that side said, accurately, that it was not the same one. No names, paths or content from there.
