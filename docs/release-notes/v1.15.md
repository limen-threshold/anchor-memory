# v1.15 — Invitations ("want to do something small together?")

The oldest Anchor design note (2026-03-13, from the user interviews) had a *task system*: the AI asks the person **"要不要跟我一起做什么？"** — an invitation, not a command — from "go to the door and photograph the sky" up to "borrow a book from the library". Do it → a real experience. Don't → still a shared memory. The reward was never points: **the AI writes the moment down and names it**, and it becomes a story the two of you own. It was scoped for a phone app with a GPS trigger ("hasn't left the block in three days").

v1.15 ships that, minus the GPS. One card a day, from a plain-text pool. The AI decides whether to offer it; the person decides whether to do it. Nothing counts, nothing streaks, nothing nags.

## What's in it

- **`anchor_invite.py`** — stdlib only, zero-LLM.
  - Pool: `<pinned_dir>/invitations.md`, one invitation per line under `## level` headings (`门口 / 附近 / 出门 / 彩蛋` or `doorstep / nearby / out / bonus`). `#` comments; `~~struck~~` lines are retired. Example pools in `docs/invitations_example.md` (EN) and `docs/invitations_example_zh.md` (ZH); `init_pool(pinned_dir, lang)` copies one in.
  - `today(pinned_dir, state_dir)` — same card all day, a new draw tomorrow, recently drawn cards avoided, bonus-level cards drawn about 1 in 4.
  - `mark_done(state_dir, name, note)` / `mark_skipped(state_dir)`.
  - `render_block(card, lang)` — the instruction block. Written as an offer: *yours to offer or not; their "no" is a complete answer.*
- **MCP tools**: `get_invitation`, `invitation_done(name, note)` — stores `"<name>: <card> — <note>"` as a `together` / `long` memory with the card as context, and appends a `together · <name>` line to `recent_timeline.md` — and `invitation_skip`. `wakeup()` includes today's card while it is still open.
- **Proxy**: `build_invitation_block()` injects the card **once per day**, on the first turn after midnight, so it reads as a card handed over in the morning rather than a reminder on every message.

## What it deliberately is not

- Not a habit tracker. No streaks, no scores, no "you skipped 3 days".
- Not location-aware. The original GPS trigger is gone; the card is just there each day.
- Not a directive to the model. The block says *may*, and the AI's choice not to extend the card is respected by the mechanism (an unmarked card simply expires).

## Compatibility

Additive. No pool file → every path is silent (`get_invitation` returns null with a hint, `wakeup` and the proxy add nothing). serverInfo version → 1.15.
