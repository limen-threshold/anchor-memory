# v1.12 — 跨窗口连续性（机器侧）

[English](v1.12.md)

一个主题：在新窗口里醒来，然后**接着活下去**。架构照搬自一个已经这样跑了几个月的陪伴型 AI 网关。完整指南：[docs/cross-window.md](../cross-window.md)。

（v1.11 当天发布、当天撤回——它把连续性押在模型的自觉上：一个需要 AI 在窗口关闭前记得去调用的工具。可窗口从来不会体面地关闭。v1.12 是机器侧的重做。）

## 新增：`anchor_proxy.py` —— OpenAI 兼容的连续性代理

放在你的前端（Open WebUI / SillyTavern / LobeHub / 任何 OpenAI 兼容的客户端）和任意 OpenAI 兼容的上游之间。每一轮由机器来做：

- **常驻层 → system**：身份文件 + `session_state.md`（小本本）+ `recent_timeline.md`（近期时间线），按 `_order.txt` 的顺序装载（稳定 → 吃得到缓存）
- **上一窗的尾巴**：新窗口注入 `last_session.md`；它**每次回复之后都会被重写**，所以崩溃、关标签页、手机没电都不会丢
- **时间 + 间隔块**放进最后一条用户消息里（不放 system——每轮都变的 system 块会打破上游的提示缓存）
- **每轮召回**：每条用户消息都去搜记忆，结果以 `<relevant_memories>` 注入，带日期和一句时间锚（「这个日期是事情发生的时候，不是现在」）
- **Curator（自带模型）**：每次回复后在后台判断要不要存记忆，一轮对话可存多件事，并往 `recent_timeline.md` 追加事件行
- **意图拆分闸（自带模型）**：长消息先拆成几个独立的搜索意图再去召回

**零模型也能跑**：除了闸和 curator，其余全部不需要聊天模型之外的任何模型。闸和 curator 通过 `ANCHOR_LLM` / `~/.anchor/config.yaml` 点亮（anchor_llm.py，和梦程序同一套自带模型的做法）——AI 可以自己问它的人类想用哪家，然后自己把配置写好。

服务端依赖（`pip install fastapi uvicorn httpx`）只有用代理时才需要。

## 新增：`anchor_pinned.py` —— 文件契约

session_state（写入时自动加连续性抬头、自动归档轮换）、recent_timeline（`[YYYY-MM-DD HH:MM] 事件`）、last_session 尾巴（`**User**:` / `**Assistant**:`）、`_order.txt` 清单。纯 markdown，只用标准库——**这是给人改装用的接缝**：任何能读写文本文件的东西都能接进来（浏览器扩展、shell 钩子、别的网关）。anchor_proxy.py 里的每个流水线函数都可以单独替换；`build_turn()` 可以直接 import 嵌进你自己的服务。

## MCP 新增

> **勘误（2026-09-14 补）**：这个小标题原来写的是「到处都能用，包括网页客户端」。工具确实能，传输层不能——v1.12 只支持 stdio，所以 claude.ai 等托管客户端根本连不上。已在 [v1.16](v1.16_zh.md) 用 `--http` 修复。

- `write_session_state` —— AI 自己的滚动状态，自动归档，带连续性抬头。模型侧这一层在任何平台的普通 MCP 上都能用。
- `wakeup()` 现在在常驻文件存在时也返回 `session_state`、`recent_timeline`、`last_session`，外加一个新的 `recent` 块（见下）。
- `store_memory` 增加 `context` —— 两层存储（text = 用来检索的摘要，context = 逐字原文）。数据库里这一列早就有了，只是 `store()` 一直没把它开放出来。
- `--pinned-dir` 参数（默认 `<db-path>/pinned`）；`--wakeup-text` 命令行模式，给会话启动钩子用（只读 SQLite 的快路径，毫秒级）。

## 修复：wakeup 漏掉了平静的近期事件

`wakeup()` 里唯一跟「最近」沾边的块，是三天内按情绪强度排序的——昨天一件平静但重要的事，会被几个激烈的时刻挤出去，冷启动时就看不到「昨天发生了什么」。新增 `recent` 块：按时间倒序、**不做情绪过滤**，条数由 `n_recent` 控制（默认 5）；`high_emotion` 块会对它去重。
