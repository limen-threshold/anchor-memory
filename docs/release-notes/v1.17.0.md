# v1.17.0 — identity files over MCP

[中文](v1.17.0_zh.md)

Prompted by a Chat-only installer (2026-09-18) who could connect Anchor to claude.ai but had no way to maintain the self-description file the README calls an *identity file*: `write_session_state` only writes `session_state.md`, and a hosted client cannot touch the pinned folder.

## New tools

- `list_identity_files()` — every `.md` in the pinned dir that `wakeup()` would load, with size, mtime, kind, and whether an `_order.txt` manifest includes it.
- `read_identity_file(name)` — the full current text of one pinned file.
- `write_identity_file(name, content, mode="overwrite"|"append")` — create, overwrite, or append. Overwrite archives the previous version to `identity_archive/<stem>_<stamp>.md`; append never loses anything. Plain `.md` basenames only (no paths, no dot-files); `session_state.md`, `recent_timeline.md`, `last_session.md`, `_order.txt` are refused (Anchor maintains those). Content capped at 30 000 chars. If an `_order.txt` exists and does not list the file, the result carries a warning: wakeup will not load it until the manifest is updated.

## Why identity files at all (the question that prompted this)

A memory is a fragment that has to win a search — or be pinned — to come back. An identity file is a whole first-person text that comes back every window, verbatim, unranked. On a hosted client both arrive through the same `wakeup()` result, so the difference is in what they are, not how they are delivered.

## Also in this release (docs, from the same installer's report)

- README: `python3` means your virtualenv's interpreter when dependencies live there (`.venv/bin/python …`, also for `claude mcp add`).
- `requirements.txt`: `fastapi` / `uvicorn` listed as the `--http` extras (`--http` failed with `No module named fastapi` when only chromadb's uvicorn was present).
- README connector step: the **space after `Bearer`** in claude.ai's *Request headers* field can get swallowed; the tunnel's request log shows the truth.
- `docs/cross-window.md`: identity files in MCP-only setups.
