# v1.31.0 — 小本本：速记、永久语录、失败记录、状态文件读数

2026-11-17。全部新增，接口不改；升级 `git pull`。四样都不要模型。

## 为什么

语义检索擅长「想起相关的事」，不擅长三件事：到期的承诺、一个字都不能改的句子、和「我上次记错了」。这一版给这三件各一个专门的地方，再加一份读数，告诉它自己的状态文件有多旧。

## 速记本 `memo_jot` / `memo_edit` / `read_memo`

对话里随口应的「回头我看一下」是一个带期限的承诺，而期限恰恰是相似度检索保证不了的。所以给一支很窄的笔：

- `memo_jot(text)`：往 `<db>/notebook/memo.md` 末尾追加一行，机器盖日期，500 字封顶。**只能追加**——不能选路径、不能覆写，换行会被压成一行（所以读着外来文字的时候拿着它也安全）。同一行同时存成一条记忆（tag `memo`），搜索也能碰到。
- `memo_edit(old_string, new_string)`：精确替换，用来把办完的一行划掉（`~~…~~` 加一句结果）或改错字。`old_string` 必须恰好出现一次，否则不动并说明；改前自动备份。
- `read_memo`：默认只看没划掉的。

**机器会把本子递回来**（`wakeup` 的 `notebook` 字段、每拍心跳和日记拍之前）：最老的几行没划掉、超过一天的，原样摆出来——办、存、划，或者不管，都是它的选择；最近两天写的几行也原样在眼前。记了没人递等于没记。

## 永久语录 `keep_quote`

必须跨过每一次状态重写的句子，不该住在状态文件里——迟早有一次重写会把它丢掉。`keep_quote(quote, who, note)` 往 `<pinned>/permanent_quotes.md` 追加一行带日期的引文；这个文件和身份文件一起，每个窗口都装载。重复的句子不重复加。改一行或删一行走 `write_identity_file`（旧版自动归档）。如果你的 pinned 目录有 `_order.txt` 而没列这个文件，回执会明说它不会被装载。

## 失败记录 `log_failure` / `list_failures`

「那条记忆是错的」需要一个安全的出口：只追加，**从不改写记忆**。七种类型：bundled（两件事融成一条）、ghost（引用了不存在的记忆）、evaporation（该浮上来的没浮）、hallucination（哪条记忆里都没有的事实）、misrecall（浮上来的是另一条）、outdated（过时的被当成现状）、tier_error（层级不对）。主语永远是「我」。存 `<db>/notebook/failures.jsonl`，另有一份人读的 `failure_log.md`，顶上写着盲区声明：这里只有浮出对话、被抓到的错，不是所有的错。

## 状态文件读数

只陈述事实，不下指令：

- `session_state.md` 上次重写是哪天、几天前；
- 里面哪些行写着「今天 / 明天 / 马上」，而这一行第一次写下的那天已经过去（日期从 `session_state_archive/` 里的历次版本推出来，轻微改写也认得出是同一行）；
- 语录册几行、最后改于哪天。

出现在 `wakeup` 和心跳/日记拍里。笔是 `write_session_state`，拿不拿起来由它定。

写入侧配一句回执：`write_session_state` 发现某行用了相对时间词、同一行又没有日期，就在回执里把这些行列出来——以后的窗口读回去，会把「明天」当成读的那天的明天。中英文时间词都认。

## 一道新闸：把提示贴回自己的文件

实跑时本机一个 30B 模型在心跳里写状态文件，把整段系统提示（语录、旧状态、门牌）原样贴了进去。现在：

- `write_session_state` 发现正文中间出现 `[continuity]` 头（它只该在最顶上、而且是机器加的），拒写并说明原因，旧文件不动；
- 心跳/房间/日记拍里，往自己文件写的内容如果带着门牌上的句子，同样拒写。
