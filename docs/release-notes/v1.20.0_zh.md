# v1.20.0 — 原话可搜、注入层体积读数、做梦时对原话核记忆

[English release notes](v1.20.0.md)

起因是 Anthropic 那篇讲 agent 记忆该有哪几层的文章：原始对话 → 小纸条 → 整理过的册子 → 开场注入的提要，外加一个「做梦」：睡着时拿原始对话核对小纸条。这版加三样，一个现有接口都没动；前两样不需要任何模型。

## 1. 原话成了正式的一层（`anchor_transcript.py`）

记忆是 TA（或管家）决定记下来的话；原话是当时真正说过的话。两样都留着，记忆看着不对的时候才有地方回去翻。

- **存哪**：`<db_path>/transcripts/日期.jsonl`，一句一行（`ts`、`role`、`text`）。格式就是全部约定——不跑代理的，自己按这个写也行。
- **代理**：每次回复完自动落这一问一答（user 那句先剥掉 `<context_now>` 注入块，再落 assistant 那句）。和最近一行一模一样的不重复落，所以客户端重发整段历史也不会一句记两遍。`ANCHOR_TRANSCRIPT=0` 关掉。
- **MCP**：`search_transcript(query, date_from, date_to, limit)`、`record_transcript(role, text)`（纯 MCP 没代理在中间的，用这个落盘）。两种传输都有。
- **怎么搜**：只认关键词和日期，中间没有模型。每个词都得出现（英文不分大小写，中文按子串）。结果按天轮流给、新的一天在前——哪天话多也不会把整页占满、把早的那条挤掉。被截断时会写明每天各有几条，缩日期范围一步到位。
- **命令行**：`python anchor_transcript.py --db-path ./anchor_data search "香港 第一次" --from 2026-10-01`；`… days` 列出有哪几天。

## 2. 开场注入那一层有了体积读数

一直挂在眼前的东西太长，模型就只扫不读。Anthropic 那篇给的上限是大约 200 行 / 25 KB；我们自家网关早撞过同一堵墙（9 万字的 system，聊天模型从来没往里看）。

- `anchor_pinned.injection_size(pinned_dir)`：`load_pinned()` 拼进去的那几个文件各多少行多少字节、合计多少、有没有超线（尾巴和邀请卡池不算）。
- `wakeup()` 多返回一项 `injected_layer_size: {lines, kb, over_limit}`。
- 代理启动时打印一行；`python anchor_admin.py <data_dir> injection` 随时看。
- 只是读数。不剪不改——把细节从 pinned 挪进记忆（能搜的那层）是人的决定。

## 3. 做梦时对原话核记忆（`dream_pass(verify=True)`，自带模型，默认关）

最近 `verify_days` 天（默认 7）存的记忆，每条拿它时间点前后 3 小时的原话，问配好的模型一句：这条记忆原话撑不撑得住？三种答案：`supported`（原话就是这么说的）/ `unsupported`（原话相反，或者没有一句说过——把 AI 的猜测记成了她说的事，也算这种）/ `unclear`（只说了一半，或原话太少看不出）。

- 每条结论写成这条记忆的一条批注（`[verify 2026-11-09] unsupported: … | 原话那一行`），再在 `<db_path>/verify_ledger.jsonl` 记一行。**不改写、不换层、不删**——v1.18 的规矩照旧，结论给看的人、给下一次做梦的人用。
- 已经带 `[verify …]` 批注的跳过；前后没有原话的记成 `no_transcript`、不批注，等有了原话再查。
- 入口：`dream_pass(verify=True, verify_days=7, llm=…)`、MCP 的 `dream_pass` 工具（`verify`、`verify_days`）、`python dream_extras.py --db … --verify --days 7 [--dry-run]`。没配模型就报 `skipped`，梦程序其余步骤照跑。
- 预算：一次最多 60 条，每条最多 6,000 字原话，输出最多 300 token。

## 测试

`python tests/smoke_v120.py`：原话落盘/去重/搜索/按天轮流、代理落盘开关、体积读数（尾巴不算、超线能报、一个字不剪）、核对器用桩模型（撑得住/撑不住/没原话、批注+账本、正文不动、不删、跑两遍不重复、没模型报 skipped）。旧测试全部不动。

## 这版没做的

图和概念链之外的「整理过的册子」那一层；Harvey 那种从评分结果里提炼教训。陪伴型 AI 没有评分，最接近的是人的纠正，而教训该由 AI 自己写进自己的 session state。
