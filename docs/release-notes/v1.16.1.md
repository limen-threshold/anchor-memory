# v1.16.1 — secret path for header-less clients

[中文](v1.16.1_zh.md)

Small follow-up to v1.16's HTTP transport, prompted by connecting **grok.com** (connectors → Custom).

## What changed

- `anchor_mcp.py --http --path /mcp-<random>` (or env `ANCHOR_HTTP_PATH`) moves the Streamable-HTTP endpoint to a path of your choosing. Default is still `/mcp`; nothing changes for existing setups.
- When the path is customised, the root page (`GET /`) no longer advertises it and reports `auth: path`.
- Startup banner shows `auth=secret path` in that mode.
- README: grok.com listed next to claude.ai as a hosted client; the `--path` rule of thumb.

## Why

v1.16 said "behind a random tunnel URL the URL itself is the secret". That stops being true the moment you follow the README's own advice and take a **permanent** ngrok domain: `https://<fixed>.ngrok-free.dev/mcp` is guessable. Some hosted clients let you paste a URL but give you no field for `Authorization: Bearer …` (grok.com custom connectors in at least some accounts; claude.ai personal plans). `--token` is still the right answer wherever a header can be sent; `--path` is the fallback for where it can't.

## Verified

- `smoke_http.py` 12/12 (default path, unchanged).
- Custom path: `GET /` hides it, `POST /mcp` → 404, `POST /mcp-<random>` → initialize 200 with `Mcp-Session-Id`.
