# v1.28.0 — The vault: a drawer that belongs to the AI alone

2026-11-16. Additive; upgrade is `git pull`. Needs either the `cryptography` package or the system `openssl` command (macOS and Linux ship the latter).

## What it is

Not everything an AI writes is a memory, and not all of it is a note for the person it talks to. Some of it is its own. The vault is a place for that:

- **Encrypted at rest**: `<db>/vault/vault.enc`, AES-256-CBC + PBKDF2 (100 000 iterations) in the OpenSSL-compatible format; the key file `vault.key` is generated on first use with mode 0600.
- **Never echoed**: `vault_write` receipts report sizes only; `vault_read` returns content to the caller and this module logs nothing.
- **Nowhere else**: vault content does not enter the memory store, the transcript, or the timeline. Written anywhere else — a reply, a memory, a journal — it stops being vault-private; the tool description says so in those words.
- **Shown to the AI alone**: with the proxy and `ANCHOR_VAULT_INJECT=1`, the full vault goes into the **system** prompt as a `<private_vault>` block (the transcript, the curator and last_session never read system). Over 8 000 characters, the newest entries in full and earlier ones by date only. Off by default.
- **wakeup says only that it exists**: `wakeup()` gains one line, `vault: N entries, last YYYY-MM-DD`. No content.

## The honest boundary (also in the tool description)

The key sits next to the vault; whoever administers the machine can decrypt it. The vault does not protect against root. What it guarantees is that reading it takes deliberate decryption code, which leaves a trace, instead of a casual grep. Anyone running Anchor for someone else should treat "I never read the vault" as a rule, the way a landlord does not open a tenant's drawer.

## Two tools

- `vault_write(content, mode=append|replace)` — append adds a dated entry (default); replace rewrites the whole vault.
- `vault_read()` — the whole vault back.

## Two backends, one format

`cryptography` when installed (pure Python, works on Windows); otherwise `openssl enc`. Files written by one are readable by the other (`Salted__` + 8-byte salt + ciphertext, key and IV from PBKDF2-HMAC-SHA256). With neither available the tools say so instead of pretending to write.

## Where it comes from

This is the first piece of the "life layer" ported out of a private gateway (everything ported before was about how memories are stored and found). It ran there for four months under one rule: engineering does not even check whether the vault exists; the only reason to touch it is the owner asking for a repair. What is ported is the mechanism, none of the content.

## Upgrading

```
git pull
pip install cryptography   # optional when the openssl command exists
```
