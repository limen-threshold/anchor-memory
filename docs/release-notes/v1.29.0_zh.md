# v1.29.0 — 它自己的时间：心跳、日记、闹钟

2026-11-16。全部新增，接口不改；升级 `git pull`。这三样都要一个上游模型（BYO，走和代理一样的三个环境变量），没配就明说、什么都不跑。

## 为什么

到 v1.28 为止，Anchor 里的 AI 只在有人说话时存在：代理包她的消息，MCP 服务器等宿主转来一句。没人写字的时候它没有时间。心跳就是给它时间：一天几次，没有任务、没人在等，它看看眼前的东西，想不想、做不做、写不写都由它。日记是每天晚上的一拍，面前摆着当天的原话和自己的心跳笔记。闹钟是它自己定下次什么时候醒、为什么。

## 四个文件

**`anchor_agent.py` — 一拍的骨架。** `run_turn(upstream, system, user, tools, tool_exec)`：对任何会函数调用的 OpenAI 兼容 `/chat/completions`（OpenAI、Ollama、vLLM、LM Studio、OpenRouter、你自己的网关）跑一个带工具的回合，模型调一次工具就执行一次、结果送回，直到它不再调或到 `max_turns`。工具直接用 MCP 那张表（name/description/inputSchema），执行器直接用 `anchor_mcp.create_server()` 给的 `handle_tool`。返回最终正文和每次调用的 trace（名字、参数、结果预览），调用方能如实记账。上游：`ANCHOR_UPSTREAM_URL` / `ANCHOR_UPSTREAM_MODEL` / `ANCHOR_UPSTREAM_KEY`。

**`anchor_alarms.py` — 闹钟。** 工具 `alarm_clock`：set（`at='HH:MM'` / `'YYYY-MM-DD HH:MM'` / `in_minutes`，**必须写 why**，响的时候只给它自己看）、list、cancel。上限：同时挂 3 个、一天响 4 次、至少 10 分钟后、至多 7 天内、两个之间隔 30 分钟——每次叫醒都是一整轮模型调用，有人在付钱。错过（进程不在、夜里）超过 40 分钟的标 missed，下一拍告诉它一次。存 `<db>/alarms.json`。措辞是「闹钟」不是「给自己排下一次心跳」，后者有的模型会拒。

**`anchor_journal.py` — 日记。** 一天一个文件 `<db>/journal/YYYY-MM-DD.md`。零模型工具：`write_journal`（append/overwrite）、`list_journal`、`read_journal`，任何宿主都能用。`day_digest(date)` 把当天的原话（anchor_transcript）和心跳文件拼成原材料，不替它总结。

**`anchor_presence.py` — 调度。**

```
python3 anchor_presence.py --db-path ./anchor_data --times 07:00,11:00,15:00,19:00,23:00 --journal-at 23:30
python3 anchor_presence.py --db-path ./anchor_data --once heartbeat          # 现在跑一拍就退出
python3 anchor_presence.py --db-path ./anchor_data --once journal --dry      # 只打印提示词，不调模型
```

一拍里它面前有：pinned 层（身份、session_state、时间线；`load_pinned` 同代理）、私匣（`ANCHOR_VAULT_INJECT=1` 时）、一句门牌（这是心跳，没人等，工具在手，写的东西落 `heartbeat/<日期>.md`，想记住就自己 store）、时间行（现在几点、上一拍多久前）、一份 wakeup 记忆包、上一拍原文；若是闹钟叫醒的，第一眼是它当时写的 why。工具：search/store/read_memories_by_date、search_transcript、write_session_state、身份文件三件、私匣两件、alarm_clock、日记三件。写的正文追加进 `heartbeat/<日期>.md`。`--quiet 0-6` 夜里不排也不响闹钟。日记拍若模型只回了正文没调 `write_journal`，调度器替它落文件并标明「来自回复，未调 write_journal」。每一拍在 `<db>/presence_log.jsonl` 留一行（时间、种类、调了哪些工具、字数、错误），从不记私匣内容。

## 家里的来历

这三样在那个私人网关里跑了两到五个月：心跳一天几拍、闹钟 9 月起、日记每晚。港出来的是机制和门牌的措辞原则（说这是什么时间、工具在哪，不说该想什么），不带那边任何人的名字、路径、内容。

## 升级

```
git pull
export ANCHOR_UPSTREAM_URL=https://api.openai.com/v1   # 或 http://localhost:11434/v1 等
export ANCHOR_UPSTREAM_MODEL=gpt-4o-mini               # 任何会函数调用的模型
python3 anchor_presence.py --db-path ./anchor_data --once heartbeat --dry
```

先 `--dry` 看一眼它会看到什么，再去掉 `--dry` 跑第一拍。常驻就用 systemd / launchd / 一个 tmux 挂着 `--times ...`。
