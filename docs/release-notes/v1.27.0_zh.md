# v1.27.0 — 从家里港过来四件

2026-11-16。接口不动；升级 `git pull`。

Anchor 是从一个私人网关里抽出来的记忆层，那边每把「记忆怎么存、怎么找」的刀都先在家里用上几个星期再港过来。这一版港的是 9 月到 11 月在家里泡稳、又符合三条家规（任何平台能用、零模型能跑、不带家里的名单）的四件。

## 1. 代理：宿主自己的旁路请求直通

Open WebUI 这类前端会从**同一个** `/chat/completions` 口子再发几种请求：生成标题、生成标签、建议追问。每一种都把整段对话包进一段 `### Task:` 提示里。它们不是人在说话。以前代理把它们当成一轮：注一块 `<context_now>`、跑一次召回、策展员再存一遍——于是记忆里出现「生成 3 个标签」，原话文件里一堆模板，每轮多两三次模型调用。

现在 `is_host_task()` 看最后一条用户消息或 system 提示是否命中这些模板（`### Task:`、`Generate 1-3 broad tags`、`Create a concise, 3-5 word title`、`Suggest 3-5 relevant follow-up questions` …），命中就原样转发，不注入、不召回、不写原话、不过策展员。

## 2. 关键词车道：带后缀的中文词同时试词根

jieba 把「姥姥家」切成一个词，于是只写了「姥姥掌勺」的记忆在关键词车道里永远搜不到。现在一小撮确定性的方位/复数后缀（家里、那边、那儿、这边、家、们、里、那、边）会被剥掉，词根**加进同一个概念组**：一行命中原词或词根都算这个概念命中一次，分母是概念组数，所以扩展不会稀释匹配分。词根至少两个字；零模型、零词表；错剥一次的代价是多一条 LIKE 候选。`keyword_groups(query)` 能看到分组。

## 3. 策展员：不认识的人只记名字，不编关系

家里 11-14 抓到策展员把一个只出现过名字的人写成「朋友」。提示里加了一句：这次对话没说这个人跟用户是什么关系，就只存名字，不要猜「朋友/同事」。只对走 BYO 模型的代理策展员生效；纯 MCP 用户不受影响。

## 4. 存侧：可选的「同场并入」

策展员逐轮重读一场还在进行的对话，会把同一幕存好几遍，相似度都卡在全库并入线（0.93）下面一点点。现在 `store(entity=<会话 id>)` 时，如果邻居的 `entity` 相同、而且是 `scene_merge_window_sec`（默认两小时）之内存的，并入线改用 `scene_merge_sim`。**默认 `None`=关**：家里那条线是在另一个 embedder 上标定的，不照抄数字；要开就自己量一次，比如 `mem.scene_merge_sim = 0.85`。

## 没港的（有意）

- 稀有字面词加分：家里只在显式查询里开，自动召回路关着，还没泡成默认值。
- 实体名册、判官、近失账、过渡桥：要么依赖家里的名单，要么要本机模型，要么还没稳。
