# v1.19.0 — input understanding and evidence review

[中文发布说明](v1.19.0_zh.md) · [Deployment guide / 中文部署指南](../input-understanding_zh.md)

Optional BYO input understanding expands only the current utterance's relevant factual, referential and contextual questions. Bilingual retrieval and an event-content/date lane make an unmentioned scheduled event eligible for recall. A separate batched reviewer checks source correspondence, retaining dates, versions, uncertainty and exact evidence. Original words, machine hypotheses and historical materials stay distinct; the responding AI retains the final response.

Proxy opt-in: `ANCHOR_UNDERSTANDING=1`. MCP-only: new `understand_and_recall`, available in both transports. No helper retains the zero-extra-model floor. Helpers never auto-store their interpretation as user testimony. Analysis is stripped from curator inputs, tails and cleaned history. Temporal injection now identifies saved timestamps as metadata, not proof an old plan already happened.

Two auxiliary calls maximum per invocation; existing curator costs are separate. Six-second wait per step by default, two in-flight auxiliary requests maximum, no work queue after a deadline. Timed-out provider computation/billing can continue. Optional local JSONL traces record interpretation, queries, candidate decisions and delivery; off by default.

Offline synthetic tests cover bilingual plans, old/new/conflicting versions, departure versus duration, multiple apple contexts, short references, missing evidence, schema failures, fabricated quotes, deadlines and outstanding-work caps, actual proxy injection and MCP-only dispatch. Existing identity, invitation, HTTP and memory-preservation smoke checks are retained. These are mechanism checks, not a semantic accuracy claim for arbitrary configured models or evidence of real-user acceptance.

See the [English guide](../input-understanding.md) for configuration, budgets and remaining limits. The helper is one step toward components that can supply evidence for each other's correction; it imposes no theory of consciousness or relational behaviour.
